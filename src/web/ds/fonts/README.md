# Fonts

Variable `woff2` files, Latin subset, served from this repository so the app makes no third-party requests.

| File                         | Family         | Licence     |
| ---------------------------- | -------------- | ----------- |
| `Nunito-normal.woff2`        | Nunito         | SIL OFL 1.1 |
| `Inter-normal.woff2`         | Inter          | SIL OFL 1.1 |
| `JetBrainsMono-normal.woff2` | JetBrains Mono | SIL OFL 1.1 |

`../tokens/fonts.css` declares the `@font-face` rules.

# Architecture decision records

An architecture decision record (ADR) captures one significant decision: the context, what was decided and what follows from it. ADRs are numbered and never rewritten; a later ADR supersedes an earlier one.

To add one, copy [template.md](template.md) to `NNNN-short-title.md` with the next number, and add it to the list below in the same pull request as the change it describes.
